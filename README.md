# Simulador-de-Caixa-Eletr-nico-em-Java
Programa em Java que reliza calculos sobre a quantidade de cedulas notas para um valor vindo de uma entrada do usuário.

O Programa é baseado em 3 funções dentro da mesma classe:

*Notas de 50: Calcula a quantidade de cedulas de 50. 
*Notas de 20: Calcula a quantidade de cedulas de 20. 
*Notas de 10: Calcula a quantidade de cedulas de 10.

O programa retorna os resultados dentro da classe principal, que pede a entrada do valor (multiplo de 10 para o usuário) e executa as funções. 
Exercicio 2 da Lista de exercícios nº3 de Extrutura de Dados 1 do curso de ADS do IFTM Campus Patrocínio.
